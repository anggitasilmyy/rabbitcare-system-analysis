# RabbitCare - Documentation Refinement

This directory contains versioned refinement addenda for the original RabbitCare v1.0 documentation. The original PDF baseline is preserved in its existing location and is not overwritten by these updates.

## BRD Refinement v1.1

The first refinement addendum records two project decisions:

- **Booking approval:** booking requests submitted by rabbit owners require admin review and approval or rejection before they become confirmed.
- **Payment gateway:** payment gateway integration is included in the MVP scope.

The addendum also documents the related business requirements, business rules, target workflows, risks, acceptance criteria, and decisions that remain open for stakeholder validation.
